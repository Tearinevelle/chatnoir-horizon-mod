# ChatNoir — мод для Horizon (Minecraft на Rust)

Сущность ChatNoir (Кот Нуар) для Horizon: локальная нейросеть в игровом чате, степени одержимости и катаклизм.

## Что умеет

- Отвечает на **любое** сообщение в чате — без команд и без упоминания имени.
- Общается через локальную Ollama (`qwen2.5:3b`), история диалога хранится в памяти мода.
- Степени: Наблюдатель → Преследователь → Влюблённый → Любовник → ОДЕРЖИМЫЙ (по 1000 очков).
- Сущность `chatnoir:chatnoir` со своим рендером и командой призыва.

## Команды

| Команда | Что делает |
| --- | --- |
| `/aiChat install` | Скачивает модель через Ollama |
| `/aiChat check` | Проверяет, запущена ли Ollama и есть ли модель |
| `/aiChat clear` | Стирает память персонажа |
| `/aiChat say <текст>` | Обратиться к нему командой |
| `/aiChat summon` | Призывает сущность рядом с игроком |

## Требования

- Horizon Launcher и установленный инстанс.
- [Ollama](https://ollama.com) на `127.0.0.1:11434`.
- Модель `qwen2.5:3b` (ставится командой `/aiChat install`).

## Сборка и установка

```sh
cargo horizon-mod build
horizon-launcher native-build . --instance "<инстанс>" --trust-native-code
```

Мод нативный: код исполняется с правами пользователя, вне песочницы.

## Структура

- `horizon-mod.toml` — манифест и пины сборки Horizon.
- `src/lib.rs` — хуки: команды, чат, тик, рендер сущности.
- `src/ollama.rs` — минимальный HTTP-клиент к Ollama.
- `src/persona.rs` — степени, память и промпты.
- `data/chatnoir/horizon/entity_type/` — тип сущности.
- `assets/chatnoir/textures/entity/` — текстура.
